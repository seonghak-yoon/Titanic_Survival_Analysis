# Titanic Survival Analysis



Python을 활용한 타이타닉 승객 생존율 데이터 분석 프로젝트입니다.



## 프로젝트 개요

- **분석 목적:** 성별, 객실 등급(Pclass), 연령 등 주요 변수에 따른 생존율 차이 탐색 및 분석

- **사용 기술:** Python, Pandas, NumPy, Matplotlib  Seaborn, Jupyter Notebook



## 주요 분석 내용

1. 데이터 전처리 및 결측치 처리

2. 변수별 생존율 시각화 및 탐색적 데이터 분석(EDA)

3. 주요 인사이트 도출



## 데이터 안내

- 분석에 사용된 원본 데이터(`titanic.xlsx`)는 저작권 및 보안 정책상 저장소에 포함하지 않았습니다.
